# 📝 Documentation Principles

I aim to keep my public projects honest, reproducible, and evidence-based:

* Document only what I actually built, observed, or verified
* Clearly identify controlled, guided, simulated, and independent work
* Distinguish confirmed observations from interpretations and assumptions
* State investigation limitations and unresolved questions
* Attribute external training platforms and source materials
* Avoid publishing restricted walkthroughs, answer keys, secrets, credentials, raw malware samples, or unsafe archives
* Separate private study notes from public portfolio documentation
* Use diagrams, screenshots, timelines, queries, and investigation reports to support findings
